# Парсер ссылок с новостных сайтов

Скрипт собирает все ссылки (`<a href>`) с главных страниц трёх казахстанских новостных сайтов и сохраняет их в CSV-файл.

## Что делает

1. Заходит на каждый сайт из списка.
2. Находит все ссылки на странице.
3. Для каждой ссылки извлекает: текст ссылки, полный URL, с какого сайта взята.
4. Сохраняет всё в `parsed_links_pro.csv`.

## Сайты

- https://nur.kz
- https://inform.kz
- https://kaztag.kz

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

После запуска в папке появится файл `parsed_links_pro.csv` с тремя колонками:
`Source_Website`, `Link_Text`, `Full_URL`.

## Технологии

- Python 3
- requests — HTTP-запросы
- BeautifulSoup4 — разбор HTML
- csv — сохранение результата
